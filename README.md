# Python Personal Records Management System

## About the Project
The **Personal Records Management System** is a beginner-friendly Python project developed to manage and store personal information efficiently.

It allows users to enter personal details and save records in a JSON file for future use.

## Features
- Add new personal records.
- Store Personal ID.
- Store Name, Age and Gender.
- Store Email Address and City.
- Save records using JSON file handling.
- Load previously saved records.
- Organize code using Python functions and modules.

## Technologies Used
- Python
- JSON
- File Handling
- Python Functions
- OS Module

## Installation and Usage

**Step 1:** Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2:** Open the project folder.

```bash
cd Python-Personal-Records-System
```

**Step 3:** Run the application.

```bash
python main.py
```
